# 04: Submission package

**What to build:** Everything a grader needs, and nothing they must not get.
`README.md` states the setup and the single run command.
`evaluation/usage_report.md` is generated from `code/cache/usage.jsonl` and
reports model providers and names, call counts, input and output tokens,
total and average tokens per request, and estimated total and per-request
cost, per model and overall. `code.zip` holds the code, the prompts, the
caches, the README and the `evaluation/` folder.
